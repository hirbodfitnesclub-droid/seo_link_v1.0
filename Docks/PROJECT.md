# PROJECT.md — LinkMesh (ابزار لینک‌سازی داخلی هوشمند)

---

## هدف بیزینس

ابزاری برای تیم‌های SEO که به‌صورت خودکار لینک‌های داخلی بهینه را بر اساس شباهت معنایی و دسته‌بندی صفحات پیشنهاد می‌دهد. فاز اول برای سایت نهال‌گشت (فروش تور مسافرتی) ساخته می‌شود؛ معماری به‌گونه‌ای طراحی شده که در فازهای بعدی به ابزاری عمومی برای هر سایتی قابل تبدیل باشد.

---

## پرسونای هدف

کارشناس SEO یا مدیر محتوا که با CSV کار می‌کند، کدنویسی بلد نیست، و نیاز دارد خروجی خود را به‌سرعت export کند.

---

## پشته تکنولوژی (Tech Stack)

| لایه | ابزار |
|---|---|
| فریم‌ورک UI | React 18 + Vite |
| استایل | Tailwind CSS v3 |
| فونت | Vazirmatn (Google Fonts) |
| دیتابیس | Dexie.js v4 (wrapper روی IndexedDB مرورگر) |
| پارس CSV | Papa Parse v5 |
| هوش مصنوعی | Gemini API — مدل `gemini-3.1-flash-lite` |
| مدیریت state | React useState + useContext (بدون کتابخانه خارجی) |
| روتینگ | React Router v6 |
| محیط ساخت | Google AI Studio Build Mode (vibe coding) |

---

## نبایدهای سخت‌گیرانه (Anti-Patterns) ⛔

این لیست مطلق است. مدل کدنویس تحت هیچ شرایطی از این موارد استفاده نمی‌کند:

| ممنوع | دلیل / جایگزین |
|---|---|
| Firebase، Supabase، هر backend خارجی | پروژه کاملاً client-side است؛ از Dexie.js استفاده کن |
| `sql.js` یا `@sqlite.org/sqlite-wasm` | Dexie.js کافی است و پیچیدگی WASM لازم نیست |
| Redux، Zustand، MobX | از React useState/useContext استفاده کن |
| Styled-components، CSS Modules، inline style | فقط Tailwind CSS کلاس مجاز است |
| هر مدل Gemini غیر از `gemini-3.1-flash-lite` | برای کنترل هزینه — مدل ثابت است |
| ذخیره API Key در Dexie یا کد | فقط `localStorage` برای API Key |
| پردازش صفحه‌به‌صفحه (loop تک‌تک) در Gemini | یک batch call واحد برای تمام صفحات |
| `axios` | از fetch native مرورگر استفاده کن |
| `moment.js` یا `date-fns` | از `new Date().toISOString()` استفاده کن |
| کامنت‌گذاری به انگلیسی در کد | تمام کامنت‌ها فارسی باشند |
